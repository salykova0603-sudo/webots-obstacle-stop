# Система обнаружения препятствий мобильного робота в Webots

Практическое задание по дисциплине «Информационные устройства и системы в робототехнике» (магистратура, 7М06103).

Робот Pioneer 3-DX едет по коридору, измеряет лидаром расстояние до коробки и останавливается перед ней. Исследуется влияние задержки обработки данных (0; 0,2; 0,4 с) на оставшееся расстояние.

## Состав

| Файл | Назначение |
| --- | --- |
| `worlds/obstacle_stop.wbt` | Мир: коридор 8 × 2 м, коробка в 3 м перед роботом, Pioneer 3-DX с лидаром |
| `controllers/obstacle_stop/obstacle_stop.py` | Контроллер: сектор ±10°, учёт положения лидара, состояния MOVE → WAIT → BRAKE → STOP, запись CSV |
| `controllers/obstacle_stop/plot_results.py` | Графики «расстояние/скорость от времени» и итоговая таблица |

## Запуск

1. Откройте `worlds/obstacle_stop.wbt` в Webots R2023b или новее.
2. Задайте поле `controllerArgs` робота: задержка, порог, метка запуска.

   | Запуск | controllerArgs |
   | --- | --- |
   | A1 | `0` `0.40` `A1` |
   | A2 | `0.2` `0.40` `A2` |
   | A3 | `0.4` `0.40` `A3` |
   | B1 | `0` `0.40` `B1` |
   | B2 | `0.2` `0.50` `B2` |
   | B3 | `0.4` `0.60` `B3` |

3. Перед каждым запуском нажмите Reset. Итог выводится в консоль, данные пишутся в `run_<метка>.csv` в папке контроллера.
4. После шести запусков выполните в папке контроллера:

   ```
   python plot_results.py
   ```

   Будут созданы `series_A.png`, `series_B.png` и выведена итоговая таблица.

## Параметры

Порог торможения: S = v·t_зад + v²/(2a) + S_зап, где v = 0,5 м/с, a = 0,5 м/с², S_зап = 0,15 м.

Смещение лидара относительно переднего бампера задано как `L = 0.03` м в `obstacle_stop.py`. Проверьте его по своей сцене.
